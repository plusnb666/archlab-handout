一、实验目的和内容

1. 实验目的

通过实验掌握 Y86-64 模型机的指令系统，理解 Y86-64 指令格式、寻址方式以及指令系统的基本功能。通过编写和运行汇编程序，理解寄存器、内存、栈、函数调用、条件跳转和循环等基本概念，了解操作数类型和指令类型，熟悉汇编程序从源代码到目标代码再到模拟执行的完整过程。

2. 实验内容

使用 Y86-64 汇编语言完成两个程序：

（1）sum.ys：遍历一个包含三个元素的链表，计算所有结点值的总和。
（2）copy.ys：将源数据块复制到目标数据块，并计算源数据的 XOR 校验和。

使用 yas 汇编器将 .ys 文件转换为 .yo 文件，再使用 yis、ssim 和 psim 模拟器运行程序，观察符号指令与机器指令之间的对应关系，并验证程序运行结果。

1. sum.ys 程序功能

sum.ys 中链表结点的数据布局如下：

    ele1: value = 0x00a, next = ele2
    ele2: value = 0x0b0, next = ele3
    ele3: value = 0xc00, next = NULL

4. copy.ys 程序功能

copy.ys 使用 %rdi、%rsi 和 %rdx 分别保存源地址、目标地址和数据长度。每次循环从源地址读取一个八字节数据，写入目标地址，同时使用 xorq 指令更新校验和，然后将两个地址分别增加 8，长度减 1。当长度小于等于 0 时结束循环。

源数据为：

    0x00a, 0x0b0, 0xc00

目标数据初始为：

    0x111, 0x222, 0x333

8. 两条机器指令分析

（1）irmovq 指令

源代码：

    irmovq $3, %rdx

机器代码：

    30f20300000000000000

分析：

    30：指令字节，其中高四位 3 表示 irmovq，低四位 0 表示函数码。
    f2：寄存器字节，f 表示没有寄存器源操作数，2 表示目标寄存器 %rdx。
    0300000000000000：八字节立即数 3，采用小端格式存储。

该指令的作用是将立即数 3 写入 %rdx，用于表示 copy_block 需要复制的元素个数。

（2）mrmovq 指令

源代码：

    mrmovq 0(%rdi), %r8

机器代码：

    50870000000000000000

分析：

    50：指令字节，其中高四位 5 表示 mrmovq，低四位 0 表示函数码。
    87：寄存器字节，8 表示目标寄存器 %r8，7 表示基址寄存器 %rdi。
    0000000000000000：八字节偏移量 0。

该指令从内存地址 0 + %rdi 中读取一个八字节数据，并写入 %r8。

四、实验小结

（一）实验中遇到的主要问题及解决方法

1. 初始构建工具链时，yas 链接阶段提示找不到 -lfl。检查后发现系统中虽然安装了 flex，但没有安装 flex-devel 开发库。安装 flex-devel、tcl-devel 和 tk-devel 后，重新执行 make clean; make，工具链构建成功。

2. 编写程序时需要正确理解 Y86-64 的内存寻址方式。链表结点的值位于偏移 0 处，下一个结点地址位于偏移 8 处；数组元素之间也相差 8 字节。通过 mrmovq 读取地址和数据，并用 addq 更新指针，解决了数据访问问题。

3. 生成目标文件后，使用 yis、ssim 和 psim 分别进行测试。两个程序均正常停止，结果为 0xcba，并且 SEQ、PIPE 模拟器均报告 ISA Check Succeeds。

（二）实验心得

通过本次实验，我理解了 Y86-64 汇编语言中寄存器、内存和控制流之间的关系。汇编语言没有高级语言中的链表、数组和函数等直接抽象，需要通过地址、偏移量、循环和跳转逐步实现。通过观察 .yo 文件，可以看到每条汇编指令都对应明确的机器字节，这加深了我对指令编码和处理器执行过程的理解。

在 sum_list 程序中，我掌握了使用指针遍历链表的方法；在 copy_block 程序中，我掌握了源地址和目标地址同步递增、计数器递减以及 XOR 校验的方法。使用不同模拟器进行交叉验证，也让我认识到程序的 ISA 行为和具体处理器实现之间应保持一致。

（三）意见与建议

建议实验指导中提供一份常见 Y86-64 指令的编码表和寄存器编号对照表，便于初学者分析 .yo 文件。后续实验可以在本实验基础上增加边界情况测试，例如空链表、长度为 0 的数据块以及负数数据。
